# Compliance Records

**Primary owner:** Privacy  
**Required reviewers:** Legal, Security, and Product  
**Authority:** `docs/10-security-and-compliance.md`

Use this directory for metadata and approved repository-safe registers such as processing inventory, lawful-basis decisions, DPIA status, provider/cross-border reviews, retention decisions, policy approvals, and data-rights process evidence.

Never commit raw personal data, identity documents, bank data, private case content, legal privileged material, provider credentials, or unredacted exports. Restricted source material must remain in an approved access-controlled system; repository records point to it using safe references.

Every record requires owner, review date, expiry/revalidation date, affected commit/release/environment where applicable, approval status, and unresolved legal/privacy conditions.
