# IAM-005 evidence

All data used by IAM-005 tests is deterministic and synthetic. No production identity, business entity, credential, or provider is contacted.

Evidence is generated by:

- `pnpm iam005:test` for exact capability, half-open validity, and IAM-004 assurance reuse;
- `pnpm iam005:integration-test` for PostgreSQL scope/template/assignment constraints, concurrency, maker-checker, service-principal isolation, and session effects;
- `pnpm db:migration-test` for forward migration, checksum, prior-schema preservation, and logical restore;
- `node scripts/test-protected-role-routes.mjs` for continued generic fail-closed protected surfaces; and
- `pnpm iam005:validate` plus `pnpm iam005:self-test` for repository-boundary enforcement.

The draft pull request records the exact head SHA and successful CI run identifiers. Passing evidence establishes the persistence foundation only; it does not activate IAM-006 policy, protected routes, infrastructure, or production data.
