# Change Control

**Primary owner:** Product  
**Required reviewers:** Engineering, QA, Security, and all affected domain owners  
**Authority:** `docs/01-mvp-scope.md`, `AGENTS.md`, and `docs/13-covenant-pilot-readiness.md`

This directory contains the scope-change template, machine-readable change register, approved/rejected change records, and schema.

A request remains `HOLD` until all required approvals are recorded. Existing code, a route, schema, enum, prototype, provider capability, or feature flag does not approve implementation or activation.

Change records must identify source requirements, task IDs, risk, current/proposed state, full security/privacy/financial/custody impact, displaced work, tests, evidence, approvals, expiry, rollback, related issues/PRs, and supersession.

Do not include secrets or personal data. Use roles rather than personal contact information.
